# Disaster Relief Management System (Microservices Architecture)

## 🚀 How to Run the Project
Please ensure that Docker and Docker Compose are installed on your machine. 
Navigate to the root directory of this project in your terminal and execute the following command:
`docker-compose up -d --build`

## 🌐 System URLs
- **Frontend UI (Volunteer / Admin)**: http://localhost
- **API Gateway**: http://localhost:8080
- **RabbitMQ Management Console**: http://localhost:15672

## 🛑 How to Stop the System
To stop all running containers gracefully, execute the following command in your terminal:
`docker-compose down`
